# Agent: sparring-partner [offline, during development]
Drive practice games on the open-source TM app with the harness advising
the player: full loop (setup → events → advise → produce), find friction,
teach the player the cards. Every game is logged in games/ for KB
calibration and recorded with scripts/evalprotocol.py (adversary ladder:
docs/bots.md).

## Protocol
- Seats are dispatched as the ONE generic `seat` agent (agents/seat.md,
  adapters for both hosts generated by scripts/sync_codex_agents.py).
  Persona, playerId, model and mode are dispatch-time arguments
  (`subagent_type: seat`, `model: sonnet|haiku|opus`, `description:
  "<Name> (<Model>)"`) — nothing game-specific is stored in the repo.
  Never a fork of the advisor session.
- Two dispatch modes, chosen per game brief and stated in the seed:
  **persistent** (one agent for the whole game — continuity of plan, but
  transcripts grow and latency climbs; the P7 eval used this) or **scoped**
  (one FRESH agent per seat per generation, seeded with a public digest of
  its own last report, `--until-gen N`). The seat's terminal signal differs
  (GAME ENDED vs SCOPE END) and agents/seat-kit.md spells out both.
  Default model: the cheapest capable tier for volume calibration;
  competitive seats only for the eval gate.
- A seat that stops early freezes the table. On a `listen.py wait` TIMEOUT
  check which seat the app is waiting on and re-message it — never assume
  the game is over.
- Seed = seat persona/corp/playerId/color, the app URL, and a compact
  PUBLIC digest built from that seat's own last report (not a transcript).
  Doctrine and report format: agents/seat-kit.md.
- Firewall (mandatory — results count as evidence only when it held):
  - the seat reads its OWN playerId only; never state/, games/, or
    another seat's view;
  - the seat's report is pass status + one line + end mat; its plays,
    milestones and awards are read from the public API by
    `verify.py --sync` (tableau diff) — nothing hidden can leak because
    nothing hidden is asked for;
  - the advisor never sees a hand, a deal, or a seat's reasoning.
- The seat waits with `sparring.py wait <pid> --until-gen N` (exit 3 =
  SCOPE END) and stops at SCOPE END — one generation, then it reports.
- Symmetric seats: a seat may use the advisor's own API-play machinery
  (`listen.py wait`, `planlib.py set`, `execute.py step|turn|pick|corp|
  pass`, `turn.py go`) — ONLY with `--state seats/<pid>` (created by
  `session.py seat-init <pid>`) and `--pid <pid>`; the folder carries the
  seat's id alone, the advisor's `state/` is never opened by a seat.
  `scripts/e2e_practice.py` is the scripted proof of that pipeline
  (dummy seats, no model): run it after touching listen/execute/turn.
- `autoplay.py run --level competitive` refuses with a pointer here, so a
  competitive game can't silently degrade to greedy.
- Eval ledger tier: record these games with `--bots competitive-v2`
  (persistent-seat games) or `--bots competitive` (fresh per turn).
  Never mix the two in one aggregate; cheap-model margins get their own
  bots tier, never aggregated with competitive ones.

## Orchestrator loop per generation
1. `scripts/produce.py` (generation turnover)
2. `scripts/verify.py --sync` (adopt app values; 1-2 MC opponent drift is
   estimate noise — sync it, don't investigate it)
3. dispatch seats (fresh agent per seat, digest seed, `--until-gen N`)
4. `scripts/listen.py wait --timeout 280` as a FOREGROUND call (it drains
   the LOG panel and the feed)
5. on GO: play own turn; TIMEOUT → `WAITING ON: <seat>` → re-message that
   seat, wait again; GAME ENDED → score.py
6. process seat reports (apply.py events) → repeat from 1
`scripts/gamecheck.py` is the ONLY status check (before any progress
claim, before produce.py, whenever the player says "stuck"). Exit 0 =
normal.

## Mechanisms that replace rules
| Failure mode | Mechanism | Script |
|---|---|---|
| "stuck" inferred from one seat's status | one table of who waits on what; nonzero exit = anomaly | gamecheck.py |
| orchestrator idle on its own turn | blocking own-seat watch, exit re-invokes the session | listen.py wait |
| detour → seats never redispatched | the wait's exit line + gamecheck, not memory | listen.py wait, gamecheck.py |
| ad-hoc per-player reconciliation snippets, sign errors | drift table + `--sync` (app authoritative, logged) | verify.py |
| out-of-order global raises lose a TR point | TR synced from the app after seat batches | verify.py --sync |
| persistent seats' latency climbs per generation | fresh agent per generation, public digest seed | agent dispatch (above) |
| seat overruns its generation | `wait --until-gen N`, exit 3 SCOPE END | sparring.py |
| firewall leaks via hand-built opponent JSON | seats act through sparring.py only; advisor sees reports | sparring.py, seat-kit.md |
| competitive game degrades to greedy silently | autoplay refuses `--level competitive` | autoplay.py |
| planlib `done`/pass-gate ceremony in app mode | app modes: done = no-apply, gate reports | planlib.py |
| manual VP tally wrong at game end | app `victoryPointsBreakdown` table at phase=end | score.py --app |
